# Hepsiburada Test Automation Suite 🚀

This is an end-to-end (E2E) UI test automation project for Hepsiburada. It is built using **Java**, **Selenium WebDriver**, and the **Gauge Framework**.

The project uses a data-driven approach for element locators and follows a clean, modular structure to make the code easy to maintain.


### Prerequisites
* Java JDK 11+
* Maven
* Gauge Framework installed on your machine
